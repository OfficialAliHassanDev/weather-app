# 🌦️ SkyCast Weather App

A modern animated weather website built using HTML, CSS, and JavaScript with live weather API integration.

## 🚀 Features

- 🌍 Live Weather Data
- 📍 Auto Location Weather
- 🔍 Search Any City
- 🎨 Glassmorphism UI
- ✨ Full Animations
- 🖱️ Hover Effects
- 📱 Responsive Design
- ⚡ Fast & Lightweight
